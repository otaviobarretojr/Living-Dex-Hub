# Living Dex Hub

Repositório oficial do projeto Living Dex Hub.

## Estado atual

- Baseline oficial: **Build 23.0 — Embedded Data Pack**
- National Dex: 1.025 espécies
- Escopo atual: Let's Go, Sword/Shield, Brilliant Diamond/Shining Pearl, Legends: Arceus, Scarlet/Violet e Legends Z-A
- Recursos centrais: Living Dex, famílias evolutivas, formas, storage/HOME, jogos possuídos, disponibilidade, exclusivos e engine de obtenção.

## Snapshot do Build 23.0

O Build 23.0 original é preservado em `archive/build-23/` como snapshot comprimido e pode ser reconstruído com o script `tools/restore_build23.py`.

A partir deste repositório, todo desenvolvimento futuro do Living Dex Hub deve ser versionado aqui.
